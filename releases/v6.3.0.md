# v6.3.0 - 修复伏笔回收、BM25 回退与事件审计链三个核心缺陷

## 发版范围

本次发布覆盖 `v6.2.1..v6.3.0`，依据两轮架构审计（2026-08-23，round1/round2）落地全部 P0 缺陷修复与 P1 结构性加固，并完成大部分 P2 优化。

## 给作者看的变化

- **伏笔账不再「只欠不还」**：用 `promise_paid_off`（读者承诺兑现）回收伏笔时，`state.plot_threads.foreshadowing` 现在会正确标记为已回收，与 `open_loop_closed` 等效。
- **检索不再静默缺块**：embedding 失败（含整批超限被拒）的章节，正文仍可通过关键词（BM25）检索，不再出现「语义检索 + 关键词检索双双丢失」的静默缺口。
- **中断后审计链不断链**：写章提交后若因崩溃中断，`projections retry` 补跑时会补齐事件审计文件与修订提案。
- **Windows 中文参数不再乱码**：PowerShell 下 `rag search --query "中文"` 等 CLI 中文查询可正常命中。
- **embedding 批次根因修复**：`embed_batch_size` 默认 64 → 20（可用 `EMBED_BATCH_SIZE` 环境变量覆盖），消除百炼接口单批超限导致的整章 `projection_failed`；实测 fantasy01 补跑 1-17 章后 vector 投影从 12 章 `skipped` 全部转为 `done`，`embedding_null` 告警清零。
- **时间线校验程序化**：新增 `timeline-check` 命令，程序化校验时间锚点填写、单调递增与倒计时算术，替代 plan 阶段 LLM 自判（实测抓出 fantasy01 第 30 章倒计时回退）。
- **写章上下文更省**：设定文件注入按 4000 字截断、上下文输出改紧凑 JSON（省 15-30% 结构冗余）、近章摘要统一 800 字截断——长篇不再随章节数膨胀写章上下文。
- **失败更可见、可纠正**：部分 chunk embedding 失败（BM25 仍可用）透出 `partial` 状态；`doctor` 新增提取质量抽查（`extraction_warnings`）；新增 `memory correct` 纠错命令。

## 是否需要改旧项目

- 无需手动迁移。此前因缺陷导致伏笔未闭合 / 检索缺块的项目，可分别用 `doctor` 检查、`projections replay` 重放补偿。
- 使用百炼 embedding 的项目如需自定义批大小，可设 `EMBED_BATCH_SIZE` 环境变量（默认已改为 20）。

## 给维护者

- `event_projection_router.py` 为 `promise_paid_off` 增加 `state` 路由；`state_projection_writer.py` 伏笔聚合分支识别该事件并走闭合路径。
- `rag_adapter.py`：`store_chunks` 在 embedding 失败（含 `embed_batch` 返回空列表）时也向 `vectors` 表写正文行（embedding 置 NULL），`bm25_search` 从 vectors 表取正文；`vector_search` 查询 norm 预计算。
- `chapter_commit_service.py`：抽出 `write_events_and_proposals` 供 `apply_projections` 与 `retry_projection` 复用；`projections.py` retry 补写 events，闭合事件链崩溃窗口；`append_projection_run` 失败记日志而非静默吞掉。
- `runtime_compat.py`：新增 `_fix_sys_argv`，就地修复 Windows 下 `sys.argv` 的 GBK/UTF-8 乱码（仅无损往返时修复，纯 ASCII、正常中文、路径不受影响）。
- 记忆四态接通生产写入：同 key 出现不同值时旧值标 `contradicted`（`conflicts()` 可透出）；data-agent 低置信（< 0.6）写入标 `tentative`，不降级现有 active 值，可用 `memory correct --status active` 升级。
- 合同 schema 版本演进：`CONTRACT_SCHEMA_VERSION` 常量 + `contract_migrations.py` 迁移框架（检测→备份→逐版本迁移→原子写回）；`doctor` 新增版本一致性检查。
- `precommit` gate 复用 run_ledger sha256 签名校验 review 与正文版本对应（`verify_review_chapter_alignment`）；`doctor` 扩展合同 JSON 校验、SQLite 三表完整性，MASTER_SETTING 多章缺失升级 error；webnovel-write SKILL 关键步骤 `run-log --append` 记录卡点。
- P2：CSV 检索 bigram 分词并收紧子串兜底；大纲截断按字段边界优先（CBN/CPNs/CEN/禁区先保留）；实体消歧 warning 与追读力 sanity 断言；`_project_total_words` 增量计算避免全量重扫。
- 版本元数据同步到 `6.3.0`。
