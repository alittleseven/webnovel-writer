# v6.4.0 - 写章上下文瘦身与实测修复

## 发版范围

本次发布覆盖 `v6.3.0..v6.4.0`（v7-tmp 开发分支），核心是把写章全流程的 LLM 上下文消耗降下来：门禁/提交/审查管线只输出一行结论、load-context 去重与紧凑化、记忆包去重、data-agent 实体定点查询；并修复真书实测暴露的两个缺陷。

## 给作者看的变化

- **写章对话更干净**：三道写章门禁（prewrite/precommit/postcommit）默认输出一行结论，完整报告落盘 `.webnovel/tmp/last_gate_<stage>.json`；chapter-commit 与 review-pipeline 也只输出一行结论——同一信息不再整包打印进对话（单章对话历史基数显著下降）。
- **写前上下文砍掉约七成冗余**：load-context 去重（合同全文与 commit 各只保留一份）、紧凑 JSON 输出、记忆包消除内部复制、状态导出限幅。35 章真实项目 A/B 实测：**load-context 输出 309,801 → 86,931 字节（−72%）**。
- **实体查询防膨胀**：`index get-core-entities` 支持 `--limit`；data-agent 契约改为「定点 get-by-alias 优先」，长篇不再无上限全量拉取实体。
- **审查产物单份化**：reviewer 持受限 Write 直写 `.webnovel/tmp/review_results.json`（唯一允许写入的文件），回复只给一行汇总；主流程不再整份落盘复述。
- **修复「中文参数被改写成乱码」**：v6.3.0 的 argv 乱码自动修复存在误报（`钱平`→`Ǯƽ`，其 GBK 编码恰为合法 UTF-8），导致 `get-by-alias` 等中文参数查询失败。argv 自动修复改为**默认关闭**；受 PowerShell 传参乱码影响的环境设 `WEBNOVEL_FIX_ARGV_MOJIBAKE=1` 显式开启。
- **CLI 对损坏 JSON 的报错更友好**：`review-pipeline` / `chapter-commit` 遇到无法解析或缺失的 artifact 时，输出定位明确的一行错误与修复提示（退出码 2），不再抛 Python traceback。

## 是否需要改旧项目

- 无需迁移。已有书项目直接使用。
- 依赖 write-gate `--format json` 默认输出的脚本需显式传 `--format json`（新默认为 `compact`）。
- 直接解析 memory_pack 中 `long_term_facts`/`active_constraints` 字段的下游需改读 `semantic_memory`（两字段已去重移除）。
- 受 PowerShell 中文传参乱码影响的环境：设 `WEBNOVEL_FIX_ARGV_MOJIBAKE=1`。

## 给维护者

- `write_gates`：新增 `format_gate_compact`（一行结论）与 `externalize_gate_report`（快照落盘）；`--format` 默认 compact。
- `chapter_commit_service.summarize_commit_payload` / `review_pipeline.summarize_review_payload`：stdout 一行摘要；完整 payload 仍由 persist_commit/落盘 artifact 承载。
- `memory_contract_adapter.load_context`：`runtime_status` 瘦身为状态字段 + commit 单份（latest==accepted 时 accepted 侧降级为章号标记），顶层 `latest_commit` 移除。
- `memory/orchestrator`：移除 `long_term_facts`/`active_constraints` 重复键；episodic 不再重复包装 state_change 行；`state_export` 列表限幅（新配置 `memory_state_export_pending_limit`，默认 10，0=不限）。
- `extract_chapter_context`：core 子段与顶层 outline/summaries/commit 去重。
- `index_entity_mixin.get_core_entities(limit)`：SQL LIMIT 下推，CLI 加 `--limit`。
- `agents/reviewer.md`：frontmatter 持受限 Write（唯一允许写 review_results.json）；webnovel-write / webnovel-review SKILL 所有权说明与 behavior eval 探针同步反转。
- `runtime_compat._fix_sys_argv`：`WEBNOVEL_FIX_ARGV_MOJIBAKE` 环境变量门控（默认关闭，误报类回归测试锁定）。
- `review_pipeline.main` / `chapter_commit._read_json`：损坏/缺失 artifact 友好报错 + `SystemExit(2)`。
