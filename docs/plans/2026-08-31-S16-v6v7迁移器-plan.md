# S16 · v6→v7 只读迁移器 实施计划

> **执行者注意：** 按任务逐个实施，TDD 红灯先行；步骤用 checkbox 跟踪。
> **Spec：** [story-repo-spec-2026-06-10.md](../architecture/story-repo-spec-2026-06-10.md)（0.4 冻结）。本计划是其 E1 迁移器的落地切片；loom-books/fantasy01 为 loom-1 原型，**不是**本迁移目标格式。
> **目标：** 一条命令把 v6 书项目只读迁移为 spec 0.4 的 v7 story-repo（book.yaml + 定稿/ + 大纲/ + 文风/ + .gitignore + git 初始提交），v6 源零写入。

## 全局约束

- 迁移器对 v6 源**只读**；输出写入 `--output` 新目录（已存在则拒绝，防覆盖）。
- 无损优先：v6 文件内容原样保留在 v7 对应位置（正文/设定/大纲/摘要），不重写内容，只加 front matter 与目录映射。
- 防呆方言（spec §2.2）：book.yaml 平铺、列表块格式、危险值加引号、UTF-8 无 BOM。
- git：`init` + `core.quotepath false` + 初始提交 `ch: v6 迁移导入`；`.gitignore` 含 `.cache/` 与 `工作区/`。
- 真书只读验证：fantasy01 迁移输出到临时目录，真书零改动。

## 任务清单

- [ ] **T1 红灯**：`test_migrate_v6_to_v7.py`——最小 v6 夹具（正文 2 章/设定集 3 件/大纲 3 件/summaries 2 条/state.json）；断言：book.yaml 字段、正文 front matter（章号/标题/卷/字数）与正文无损、设定与大纲映射、摘要落位、.gitignore、源未动。
- [ ] **T2 实现**：`scripts/migrate_v6_to_v7.py`——`migrate_project(project_root, output, use_git=True) -> MigrationReport`；卷号从 `大纲/第N卷-时间线.md` 行解析（`第36章`→卷 N），缺省 1；`名册.md` 从 `.webnovel/index.db` entities 生成（库缺失则跳过并记 warning）；`风格宪法.md` 仅当源有 `设定集/风格契约.md`。
- [ ] **T3 CLI**：`--project-root --output --no-git`；输出 MigrationReport（章数/字数/skips/warnings）。
- [ ] **T4 集成验证**：fantasy01 → 临时目录真实迁移：36 章、book.yaml 书名/类型断言、git log 含初始提交、v6 源 mtime/内容未变。
- [ ] **T5 收尾**：全量 pytest + evals、队列 S16 回写、CHANGELOG、提交推送、指针同步、自检。
