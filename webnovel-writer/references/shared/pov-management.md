# POV 管理与视角纪律（共享参考）

> M5/T27（R11/F-16 技法盲区补齐）。供 context-agent（人物段）、write（起草/润色）按需读取。

## 一、单章视角纪律（默认：单章单视角）

- 视角人物的**五感是唯一镜头**：只有他能看到的、听到的、闻到的、推知的才能上纸。
- 他人情绪只能**外显**（表情/动作/语气/沉默），不得直写"他心想/她感到"。
- 视角越界自检（每章一遍）：逐段问"视角人物此刻能感知到吗？"——不能感知的信息一律改写为可感知线索。
- 禁止"上帝视角点评"（"他不知道的是……"属机械开场收尾词，见 polish-guide J 类）。

## 二、多 POV 切换规则（女频群像/悬疑多线适用）

1. **切换单位是场景，不是段落**：同一场景内禁止换视角；换章或用分隔符（--- / ◇）。
2. **一章最多两个视角**；每个视角块自带完整微弧（压力→反应→钩子）。
3. **视角选择原则**：谁在场景里损失最大，镜头给谁。
4. 同一事件需要双视角时，第二视角必须提供**新信息**（另一方的动机/隐情），否则是复播。

## 三、视角越界常见病与修法

| 病灶 | 例 | 修法 |
|------|-----|------|
| 内心直录他人 | "他心想她真幼稚。" | 改外显：他把她的方案推回去，没说话。 |
| 全知预告 | "她还未察觉，危险已至。" | 改视角内线索：她背后的影子比路灯先动。 |
| 双头视角 | 同段先写甲的紧张再写乙的窃喜 | 拆成两段，各归各的视角块 |
| 镜头漂移 | 视角人物不在场的事件实写 | 改转述/审讯/监控等带原因的信息渠道 |
