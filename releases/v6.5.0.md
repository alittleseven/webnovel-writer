# v6.5.0 - 写章上下文与往返深度优化（Phase C/D 收官）

## 发版范围

本次发布覆盖 `v6.4.0..v6.5.0`（v7-tmp 开发分支），完成单线队列 S1-S11：上下文预算实装（C1-C4）、上下文减负收尾、字段名统一、读侧性能、杂项三项、往返压缩、大输出外置化与模型路由指引。

## 给作者看的变化

- **写前上下文包预算实装（C1，S1）**：`load_context` 的 `budget_tokens` 从死参数变为真执行——按 section 配额 + 键优先级收缩（`source_trace` 等元数据不再进入上下文；上一章提交全文只保留 meta 与摘要一句）。默认总预算经 [S1 配额分析](../docs/reports/2026-08-30-S1-预算配额分析.md)（fantasy01 实测）定为 **20,000 字符**：ch35 基础包 59,977 → **19,241 字符（−68%）**，`budget_used_tokens` 返回真值。硬约束类（合同/运行状态）永不整体丢弃。
- **ContextManager 路径同步瘦身（C2，S2）**：extract-context 降级路径与主路径对齐——runtime_status 瘦身、四个大 section 文本上限（genre_profile 1500 / reader_signal 800 / writing_guidance 1200 / plot_structure 2500）、`build_context` 的 `max_chars` 死参数落地为总预算（超限低价值先弃、`meta.budget_dropped` 留痕）。fantasy01 ch36 实测：extract-context 39,914 → **17,304 字符（−57%）**。
- **设定集 L0 摘要层（C3，S3）**：设定内容默认注入 ~240 字结构摘要（主题行 + `##` 骨架 + 首要点），源文件变更自动重建（sha256 陈旧自愈，不依赖 init/plan 重跑）；原文（L2）经 `setting-read --name <设定名>` 按需展开。fantasy01 实测：6 个设定文件 9,008 → **601 字符（−93%）**；`context_settings_digest_enabled=false` 可回滚。
- **章纲预算补完（C4 残留，S4）**：拆分章纲文件（`大纲/第N章-标题.md`）不再绕过 1500 字预算整份注入；`plot_structure` 默认限量 4000 字。
- **上下文减负收尾（S5）**：删除 4 个已迁移的 reference 空壳；loading-map 增补加载方式对照表；行为 eval `write_blocking_gate` 从文案断言升级为运行时探针。
- **大纲字段名统一（S6）**：章纲节点字段收敛为单一准绳 `must_cover_nodes`/`forbidden_zones`（与书项目合同一致，数据无需迁移）。
- **读侧提速（S7）**：`commits/latest.json` 提交指针（写侧维护、读侧失效自愈回退扫描，跳章场景测试锁定）；graph RAG 候选 term 过滤下推 SQLite。
- **杂项三项（S8）**：新实体别名预注册（3-5 个，`new_entity_few_aliases` 提示）；题材套路库 6→9 节（悬疑/科幻/历史）、题材画像 13→14（科幻）；正文手改 PostToolUse 留痕 hook（不阻断）。
- **写章往返压缩（S9）**：`preflight --all` 三查合一（写章起手 3 次往返并作 1 次）；`run-ledger record-write-steps` 批量记账（崩溃粒度由 run-log 保留）。
- **CLI 大输出自动外置化（S10）**：进程内命令 stdout 超 20,000 字符自动落盘 `.webnovel/tmp/cli_out/<tool>.txt`，对话只留摘要存根；`WEBNOVEL_OUTPUT_EXTERNALIZE=0` 关闭。
- **模型路由指引（S11）**：新增 [模型路由操作卡](../docs/guides/model-routing.md)——reviewer/data-agent/context-agent 可一行切到便宜模型（含冒烟验证与质量抽检协议）；默认 `inherit` 不变。

## 是否需要改旧项目

- 书项目数据**无需迁移**（字段名统一的准绳名即真源合同现用名）。
- 兼容性提示：直接消费 `plot_structure` 旧键名（`mandatory_nodes`/`prohibitions`）的外部脚本需同步改名；直接解析 memory_pack 中 `long_term_facts`/`active_constraints` 的下游改读 `semantic_memory`；依赖 write-gate `--format json` 默认输出的调用需显式传 `--format json`（新默认 compact，v6.4.0 起）。
- 新增环境变量（均可选）：`WEBNOVEL_OUTPUT_EXTERNALIZE=0` 关闭大输出外置化、`WEBNOVEL_OUTPUT_EXTERNALIZE_CHARS` 调阈值、`WEBNOVEL_FIX_ARGV_MOJIBAKE=1`（v6.4.0 起，PowerShell 传参乱码环境）。
