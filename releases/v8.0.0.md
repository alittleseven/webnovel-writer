# v8.0.0 - 作者主权 + 300 章连贯（webnovel-copilot-300 工程落地）

## 发版范围

本次发布覆盖上个正式 tag `v7.0.0` 之后的 `v7.1.0..v8.0.0`（`v8-author` 分支，单线队列 T1-T34，方案文档集见 `docs/zcode/webnovel-copilot-300/`）。目标一句话：把插件从「能写章」升级为「能帮作者连贯写 300+ 章」——以作者主权七原则为宪法，在 v7 书仓之上叠加六域治理层（大纲/素材/设定/正文/文风/作者），全部确定性脚本兜底，AI 只提议、作者只确认。伏笔失控、战力通胀、设定漂移、文风漂移、卷纲失对账五类长篇病全部有机器闸。

## 给作者看的变化

- **六域书仓骨架**：`domains init` 一键建骨架（大纲/素材/设定/正文/文风/作者 + 书项目 AGENTS.md），幂等、永不覆盖既有内容；init 时按题材自动播种素材（4 表 × ≤30 条）。
- **作者修改自动留账**：会话启动 `author-sync` 把 git diff 分类成六域 journal 事件（0 token）并生成影响摘要；stale 标记在下次写章前置注入「作者已改」。
- **总纲三区 + regen 画廊**：甲区冻结/乙区活跃/丙区锚点；总纲与章纲 regen 走版本画廊（≤3 版），采纳才写回正典。
- **章纲批量**：一批 ≤8 张 + 批内自检 + 一次确认；卷纲时间线视图可导出可回写。
- **freeze/retcon**：卷收尾快照素材到 `定版/v{NN}`；改定版触发影响清单 + 三选项裁决（只改今后/全书 retcon/放弃）。
- **成长素材库**：活层十表 + 定版快照 + 使用轨迹；AI 归纳与拆书投喂先进画廊；material-review 卷审（衰减/合并/淘汰裁决）。
- **作者模型与文风域**：`learn --from-journal` 卷级归纳（作者确认后回写 author_model + 跨书偏好）；指纹计算器对全书定稿确定性计算；金句库标记可自喂进台词金句素材表；style_anchor 高分样本自动进写前上下文。
- **设定工坊**：境界/功法/法宝/命名四生成器（提案模式，红线程序化强制：不出战力数值、灵魂设定标注、恰 5 组提案）。
- **战力校验**：力量锚点半自动抽取 + 战例账本 + power_check（越级无依据 → high 阻断级问题；通胀曲线软提示）。
- **连贯性专项**：承诺账本逾期扫描（门禁语义）、时间线年龄/修龄推演列、命名冲突检查（编辑距离）、卷纲-实际对账报告（节点覆盖率/伏笔兑现/战力里程碑，freeze 自动产出）。
- **质量轨整编**：上一章原文尾段进上下文（保护级）；prose_check 程序化文笔检测 + reviewer 第 6 维（ai_flavor 反模式回流）；`--drafts 2` 多稿择优（rubric 落库校准）；追读力信号与审查趋势进主路径；写作 CSV 触发面 5→9。
- **体验层**：MCP 9→14 个只读工具（素材/装配/战力/逾期/追读力）；`/webnovel:*` 命令 9→13（materials/forge/power/style）；dashboard 新增治理面板（六视图只读）；userConfig 增 `draftsPerChapter` 与 `materialTopK`。
- **300 章规模演练**：`scale_drill` 合成 300 章书仓全链实测 1.64s（doctor/timeline/逾期扫描/素材装配/对账），远优于分钟级预算。

## 是否需要改旧项目

不需要迁移。既有 v6/v7 书仓直接可用；运行 `webnovel.py domains init` 幂等补齐六域骨架与素材播种（已存在内容一律不覆盖）。`作者/author_model.md`、`文风/宪法.md` 等随对应里程碑按需生成。
