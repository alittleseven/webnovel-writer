# v7.0.0 - Story Repo 主轴上线（迁移 → 两章实跑落定 → 按书校准 → 审阅加固）

## 发版范围

本次发布覆盖 `v6.5.0..v7.0.0`（v7-tmp 开发分支），完成单线队列 S13-S26：v7 story-repo 新架构从迁移器、缓存、唯一写入路径到**第 37/38 章两章真实落定**的完整闭环；配额按书校准（分析与实施）；两轮代码审阅与修复批；章级计量聚合修复。v6 写章链路（`/webnovel-write` 全流程）保持不变，v7 为并行新链路，作者按书选择。

## 给作者看的变化

- **v6→v7 只读迁移器（E1，S16）**：一条命令把 v6 书项目只读迁移为 v7 story-repo（book.yaml、定稿正文 spec 命名 `NNNN-标题.md`+中文键、设定、章摘要、大纲、git 初始提交）；对 v6 源零写入（测试含 mtime 断言），输出目录已存在即拒绝。
- **v7 缓存与「派生物可丢弃」（E2，S17+S25）**：`.cache/index.db` 从源文件全量重建（每次重建重读源），`verify` 子命令执行「删光缓存→重建→查询快照等价」CI 验收；坏库/缺表/零字节缓存首查自动重建自愈。
- **双格式唯一写入路径（E4，S18+S26）**：同一章节在 v6/v7 双格式期间只允许一种格式落定，另一侧落定即阻断（blocker `dual_format_write_blocked`）；迁移器可落 `dualformat.v6root` 映射，`--link-back` 可选激活 v6 侧守卫（默认零写入不变）。
- **v7 写路径闭环 + 两章实跑（E3，S19；审阅实测）**：决策卡 → 上下文包（20,000 字符预算）→ 草稿 → 机检（字数契约按书史校准、占位符、标题一致、承诺豁免、名册 advisory）→ 作者验收 → settle 原子 commit（含 S18 校验、失败自动回滚并清理 git index）。fantasy01 第 37 章《暗纸》、第 38 章《回纸》两章全链路实跑并经作者验收落定（`30744af`/`a4def9c`）；上下文包实测 2,691-3,242 字符（v6 链路 17,304 的 −81%），子代理 0 派发。复盘与计量对比见 [S20 报告](../docs/reports/2026-09-02-S20-v7垂直切片复盘.md)。
- **section 配额按书覆盖（S22 分析 + S23 实施）**：book.yaml 可选 `context_budget:` 节按书覆盖总预算与节配额（优先级 显式参数 > book.yaml > 内置默认，不写零行为变化）；迁移器对 ≥3 章的书按书史字数自动预填上一章结尾节配额（实测唯一触顶节）；v6 侧总预算支持 `WEBNOVEL_CONTEXT_LOAD_TOTAL_BUDGET` 环境变量；v7 包 stats 与 v6 `enforce_budget` 均输出 `truncated_sections` 占用信号。分析结论见 [S22 报告](../docs/reports/2026-09-02-S22-配额确定时机分析.md)。
- **v7_cache 名册双落点（审阅 P1，S24）**：兼容读 `名册.md` 单表与 `名册/<正名>.md` 目录（同名目录优先），实体含首现章——v7 原生新书（不经迁移）的实体查询面修复。
- **settle 加固（S25/S26）**：章号前缀判重防双写；回滚逐文件保护 + reset 范围化；git 身份兜底与 stderr 透出；settle 尾迹自动 rebuild 缓存（best-effort）。
- **守卫与安全加固（S26）**：precommit 补挂双格式守卫；dashboard 默认 `mode=ro` + 非回环地址显式确认；rejected 状态机单调化；doctor `total_words` 双源对账；backup 回滚删新增文件；`run_ledger` 原子锁化；memory 批量 upsert。
- **章级计量聚合修复（D1，S13 实测发现）**：meter start 在写作会话首轮完成前的会话误推断导致漏计主会话——聚合语义改为「窗口内全部轮次」，主会话清单显式透出，并行多主会话输出 `WARN parallel_main_sessions=N`；fantasy01 ch36 真值重放 2,853,338 与手工聚合一致。
- **Windows 编码收口（S24/S26）**：SKILL 全部裸 `python` 补 `-X utf8`（dashboard evals 契约同步演进）。
- **spec 0.5（作者批准生效）**：六项实测形态偏差显式登记（名册双落点、settle commit 格式、章 front matter 键、决策卡形态、book.yaml `context_budget:` 嵌套例外、承诺系统排期 v7.1）；[多宿主适配立项决策](../docs/decisions/2026-09-02-多宿主适配立项决策.md)：立项，排 v7.0.0 后独立开队列，首期单宿主 ZCode。

## 是否需要改旧项目

- **v6 书项目无需任何迁移**——v7 是并行新链路，仅当作者主动运行迁移器时生成新仓；`/webnovel-*` 8 命令习惯不变。
- v7 仓的 `context_budget:` 为可选节（缺省行为不变）；v6 侧新增可选环境变量 `WEBNOVEL_CONTEXT_LOAD_TOTAL_BUDGET`（per-book 总预算覆盖）、`STORY_REPO_ROOT`（v7 仓根，双格式守卫缺省空=零行为变化）。
- v7 新入口三脚本（migrate/v7_cache/v7_write）用法见 [v7 写路径指南](../docs/guides/v7-write-path.md)；承诺结转（spec §5）排期 v7.1，当前机检仅校验「承诺非空或显式豁免」。
