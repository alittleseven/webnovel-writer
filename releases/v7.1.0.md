# v7.1.0 - ZCode 原生化（清单迁移 → MCP 服务 → 斜杠命令 → userConfig）

## 发版范围

本次发布覆盖 `v7.0.0..v7.1.0`（`tmp/zcode` 分支，单线队列 S1-S16，方案文档集见 `docs/zcode/zcode-native-adaptation/`）。目标一句话：把 webnovel-writer 从「Claude Code 插件靠 ZCode 兼容层运行」升级为「ZCode 原生插件」，并用 ZCode 独有能力面（插件 MCP / userConfig / 命令冒号命名）强化查询与定位体验。多宿主 ADR（2026-09-02）的首期 ZCode 宿主正式化即本版本。写章链路（v6 `/webnovel-write` 与 v7 story-repo）零改动。

## 给作者看的变化

- **ZCode 原生清单**：插件本体迁移到 `.zcode-plugin/plugin.json`（ZCode 第一优先探测位），显式声明 skills/hooks/agents/commands 组件；marketplace 清单双位置镜像（仓库根 + `.claude-plugin/`），未来 ZCode UI 刷新/重装两种探测位都吃得开。
- **自带 `webnovel` MCP 服务**：会话启动自动连接，9 个只读查询工具——项目状态、体检（doctor）、设定读取、时间线校验、token 计量、RAG 语义检索、实体/关系查询、上下文预算预览、项目根解析。模型不再需要拼 Bash 长命令，结构化输出直接可用。只读红线：不暴露任何写路径工具，写操作仍走 skill 编排保留人工审阅语义。
- **`/webnovel:*` 斜杠命令**：`/webnovel:status` `/webnovel:doctor` `/webnovel:query` `/webnovel:write` `/webnovel:plan` `/webnovel:review` `/webnovel:init` `/webnovel:learn` `/webnovel:dashboard` 九条短名入口（薄壳，业务仍在 skill/CLI，无双实现漂移）。
- **书项目根 GUI 配置（userConfig）**：Settings → Plugin Management → webnovel-writer → Advanced →「书项目根目录」。填写后注入 `WEBNOVEL_BOOK_ROOT`，MCP 查询与脚本缺省定位到该书项目；留空则按既有探测链（显式参数 > 会话工作区向上 > 指针/registry）。
- **宿主环境变量原生化**：hooks 与脚本统一 `ZCODE_*` 优先、`CLAUDE_*` 回退；工作区指针文件同时探测 `.zcode/` 与 `.claude/` 两个位置；用户级 registry 在 `~/.zcode` 有数据时优先。
- **修复**：`run_tests.ps1` 的 `.claude/scripts/…` 陈旧路径（上游布局遗留，此前必然跑不起来）修正为实际路径。

## 给维护者

- 组件清单：skills×8、agents×4、hooks×4（SessionStart/UserPromptSubmit/PreToolUse/PostToolUse，事件全部在 ZCode 支持的 7 种内，模板变量改 `${ZCODE_PLUGIN_ROOT}`）、commands×9、MCP×1（`mcp/server.py` 纯标准库 stdio JSON-RPC，adapter 模式 subprocess 调 `webnovel.py`，零第三方依赖）。
- 发版脚本（sync_plugin_version / validate_plugin_package / validate_release_notes / run_behavior_evals）双布局探测（`.zcode-plugin` 优先）；marketplace 双位置由 sync 脚本镜像写入并 check 校验一致。
- 测试：新增 26 条 MCP 协议/路由测试 + 13 条清单校验双布局测试 + 2 条定位器 ZCode 用例；pytest.ini testpaths 增 `webnovel-writer/mcp/tests`。
- 装机：本机 marketplace 换源至 `projects/zcode-plugins/webnovel-writer`，文件级装卸手册见 `docs/zcode/zcode-native-adaptation/05-install-reinstall-runbook.md`（旧 6.5.0 缓存改名留存可回滚）。

## 是否需要改旧项目

不需要。书项目数据格式零变化；既有 v6/v7 写作链路行为不变。已装 6.5.0 的 ZCode 用户升级本版本后，建议在插件 Advanced 里配置一次书项目根目录（可选）。
